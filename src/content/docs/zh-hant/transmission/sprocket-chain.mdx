## 中心距

:::note

鏈條可以拆卸並增減鏈節，因此可依以下順序設計：

1. 依機器人結構決定兩個鏈輪的中心距。
2. 依中心距調整鏈條長度。
3. 調整張緊程度，讓鏈條與鏈輪正常配合。

:::

:::caution

* 中心距不可太小，以免鏈輪互相干涉。
* 中心距不宜過大，以免鏈條難以維持適當張緊程度。

:::

## 鏈條張緊

鏈傳動需要適當的鬆緊程度，才能穩定運作。

### 為什麼需要調整張緊程度？

**鏈條過鬆：**

* 容易跳齒或脫鏈
* 磨損加快
* 空行程增加，機構反應變慢

**鏈條過緊：**

* 鏈條、軸承與軸承受過大負載
* 摩擦增加，耗費馬達動力
* 零件壽命縮短

**張緊適中：**

* 傳動順暢可靠
* 磨損較少
* 傳動效率較佳

<DocImage src="/assets/docs/transmission/tension.png" alt="鏈條張緊程度示意" width={375} />

#### 張緊調整方式

<Tabs>

<TabItem label="調整鏈條長度">

使用截鏈器與接頭鏈節（Master Link），即可增減鏈節數量。

**適用時機：** 鏈條明顯過鬆或過緊。

</TabItem>

<TabItem label="調整中心距">

移動鏈輪位置，改變兩根軸之間的中心距。

**適用時機：** 結構設計階段，或安裝位置留有調整空間。

**限制：** 可能需要重新設計安裝結構。

</TabItem>

<TabItem label="張緊器（非閉環鏈條）">

<DocImage src="/assets/docs/transmission/tensioner_usage.png" alt="張緊器用於非閉環鏈條的示意" width={375} />

* 適用於鏈條不繞行完整閉環的機構
* 旋轉中間的調整旋鈕即可拉緊鏈條

</TabItem>

<TabItem label="惰輪（閉環鏈傳動）">

<DocImage src="/assets/docs/transmission/idle_gear.png" alt="以惰輪調整閉環鏈條的張緊程度" width={375} />

* 在鏈條路徑中加入一個小鏈輪
* 可設於鏈條環的內側或外側
* 增加鏈條與鏈輪的嚙合範圍，讓傳動更穩定

:::note

惰輪可調整張緊程度，不會改變傳動比。

:::

</TabItem>

</Tabs>

## NICE 鏈條張緊器

<BuyButton href="https://item.taobao.com/item.htm?id=1007154306593&mi_id=0000os9LBqznREtiA5NSsLmaF1jkBytMTOSSjCu5g10xdpM&spm=a21xtw.29178619.0.0" />

<DocImage src="/assets/docs/transmission/tensioner.png" alt="NICE 鏈條張緊器" width={375} />

安裝方式：

1. 將兩端的固定螺栓從中間旋鈕旋出。
2. 使用截鏈器，將固定螺栓分別接至鏈條兩端。
3. 將兩根固定螺栓同時對準旋鈕兩端。
4. 旋轉旋鈕，將鏈條拉緊。

:::danger

此張緊器僅適用於鏈條不繞行完整閉環的機構。若張緊器移動至鏈輪處，將損壞鏈輪！

:::

* 調整旋鈕適用 M6 螺栓，連接穩固
